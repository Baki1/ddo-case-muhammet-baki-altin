# KütüphaneNet — Üniversite Kütüphane Yönetim Sistemi

Bu proje, DDO Yazılım Ekibi alım süreci için Muhammet Baki Altın tarafından geliştirilmiştir.

## Hızlı Başlangıç

Projeyi tek komutla ayağa kaldırmak için:

\`\`\`bash
cp .env.example .env
docker compose up --build
\`\`\`

- **Frontend:** http://localhost:3000
- **Backend (Go API):** http://localhost:8080
